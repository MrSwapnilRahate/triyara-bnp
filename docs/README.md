# Triyara BNP - Documentation

Master documentation standard: **TRY-BNP-DOCS-01**. Every document has a stable ID
(`TRY-BNP-<TYPE>-<NN>`) and one home in the numbered folders below.

| Folder            | Contents                                 |
| ----------------- | ---------------------------------------- |
| `00-overview`     | Vision, goals, roadmap, index, glossary  |
| `01-architecture` | ARCH-01, EXT-01, DB-01 + diagrams        |
| `02-product`      | PRD-01, UX-01, trust & evidence strategy |
| `03-engineering`  | TDR-01, API-01, DEV-01, coding standards |
| `04-design`       | UX patterns, tokens, components          |
| `05-development`  | Setup, workflow, testing                 |
| `06-operations`   | Runbooks, monitoring, incidents          |
| `07-deployment`   | Environments, CI/CD, rollback            |
| `08-learning`     | Engineering knowledge base               |
| `09-decisions`    | Architecture Decision Records (ADR)      |
